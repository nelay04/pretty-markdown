# Bash Commands for Node.js and System Updates

```bash
# Check Node.js version
node --version

# Update package list
sudo apt update

# Upgrade packages
sudo apt upgrade

# Check npm version
npm --version

# Check system information
uname -a

# List installed packages (example)
dpkg -l | head -10
```

# Additional Commands

```bash
# Check disk usage
df -h
```

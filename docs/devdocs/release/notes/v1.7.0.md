### Added

- **Maths**: LaTeX written as `$E = mc^2$` or in a `$$ ... $$` block is typeset with KaTeX, in the preview and in exported PDFs alike. The fonts travel with the export, so an equation looks the same on a machine that has never seen the document.
- **GitHub-flavoured alerts**: a blockquote starting with `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` or `[!CAUTION]` becomes a titled callout, with an accent colour per kind that follows the theme and can be overridden through `prettyMarkdown.colors`.
- **Task lists**: `- [x]` and `- [ ]` render as checkboxes instead of literal brackets.
- **Footnotes**: `[^1]` references link to a numbered list at the foot of the document, and back again.
- **Section links**: every heading gets a GitHub-style anchor, so a hand-written table of contents navigates both the preview and the exported PDF.
- **More inline syntax**: `==highlighted==` text, `H~2~O` subscripts and `x^2^` superscripts, plus styling for definition lists and `<kbd>` keys.
- **Offer to install Chrome's missing libraries (Linux)**: where Chrome cannot start for want of system libraries, the export offers to install them instead of only naming them. Package names come from your own package manager, so Ubuntu 22.04 and 24.04 or later each get the right ones.

### Changed

- **Front matter is no longer printed**: a YAML block at the top of a document used to open the page as a rule and a wall of `title: ...` text. It is now treated as metadata and left out.
- **Collapsed sections are exported open**: a `<details>` section folded away in the preview exported as its summary line alone, losing the content inside it. Exports now expand every section first.
- **Themes have names**: the `default` and `dark` presets are shown as **Pretty Light** and **Pretty Dark**. The values in `settings.json` are unchanged, so existing configurations keep working.

### Fixed

- **Diagrams match the rest of a dark page**: on Pretty Dark, diagrams were drawn on a white canvas inside a dark document, and clusters, notes and sequence actors each picked up a different grey. Every diagram surface now comes from the theme.
- **Exported PDFs are no longer framed in white**: a themed export left the page margins as bare white paper, plainly visible on Pretty Dark. The margins now carry the theme background, in both the Chrome and the built-in export.

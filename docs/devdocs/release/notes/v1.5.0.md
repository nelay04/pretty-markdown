### Added
- **Mermaid diagrams**: ` ```mermaid ` and ` ```mmd ` fences are drawn as diagrams in the preview, in exported PDFs, and in the web build. A diagram that fails to parse keeps its source text instead of breaking the document.
- **Local images**: images referenced relative to the Markdown file load in the preview and are embedded in exported PDFs.
- **Clickable links in the preview**: links to other Markdown and workspace files open in the editor, `http(s)` and `mailto` links open in the browser, and `#anchor` links still scroll within the preview.
- **PDF export without Chrome**: when no usable Chrome is available the export falls back to the bundled converter instead of failing. The PDF is an image, so its text is not selectable, and the reason is shown alongside it.

### Changed
- **Chrome is reused, not re-downloaded**: the browser is looked up in `PUPPETEER_EXECUTABLE_PATH`, the shared `~/.cache/puppeteer` cache, the previous per-profile cache, and the system installation. Any existing build is used instead of fetching the newest release, and downloads are shared across VS Code stable, Insiders, and the Extension Development Host.
- **The Chrome download is opt-in**: it is shown with its size and offered only on systems that can actually run Chrome, and progress reports the real percentage and total.

### Fixed
- **The export notification no longer sticks**: a browser that failed to exit used to leave "Exporting to PDF..." on screen indefinitely. It is now closed with a timeout, force-terminated if needed, and always released even when the save dialog is cancelled.
- **Interrupted browser downloads self-heal**: a partial download used to fail every later export with `end of central directory record signature not found`. The incomplete files are cleared and the download retried.
- **Missing Linux libraries are reported clearly**: instead of a raw loader error, the export names every missing library and the exact install command for the detected distribution (apt, dnf, or pacman).
- **Dependency security advisories resolved**: `npm audit` reports no vulnerabilities.
